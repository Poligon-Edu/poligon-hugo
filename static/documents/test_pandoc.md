# Document pentru testarea pandoc
Acesta este un document cu format markdown.

El poate să conțină *text italic*, **îngroșat** sau ~tăiat~.

Poate conține și liste nenumerotate:
- primul element;
- al doilea element;
    + primul sub-element al celui de-al doilea element;
- al treilea element.

Putem include și citate:

> Repetiția este mama învățăturii. (proverb latin)

Și ceva matematică: $\sqrt[3]{27} = 3$ sau centrat:

$$
\int x^2 + 1 dx = \dfrac{x^3}{3} + x + \mathcal{C}.
$$

---

Listele numerotate arată astfel:

1. Primul element;
2. Al doilea element;
3. Al treilea element.
